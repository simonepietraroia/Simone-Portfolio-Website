# Simone Pietraroia Portfolio

## Overview

This project is a personal **software engineering portfolio website** built using **React and modern frontend technologies**.  
The website showcases my **technical skills, professional experience, projects, and contact information** in an interactive and visually engaging format.

The portfolio includes smooth animations, dynamic content rendering, and responsive design to provide a polished user experience across devices.

---

# Features

- Animated hero section with typewriter effect
- Smooth scroll navigation
- Interactive project cards
- Skills section with categorized technologies
- Professional experience timeline
- Animated background effects
- Responsive design for mobile and desktop
- Downloadable CV
- Direct contact links
